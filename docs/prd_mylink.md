# 마이링크 PRD

## 1. 문서 목적

이 문서는 링크트리 클론 서비스인 마이링크의 기능과 구현 범위를 정의합니다.

현재는 전체 서비스를 한 번에 만들지 않고, 시연 순서에 따라 가장 기본적인 **프로필 페이지**부터 단계적으로 구현합니다.

## 2. 서비스 소개

마이링크는 개인 크리에이터와 일반 사용자가 자신의 프로필, 소셜 미디어, 여러 링크를 하나의 페이지에 모아 공유하는 서비스입니다.

공개 페이지는 다음과 같은 형태를 목표로 합니다.

```text
mylink.com/사용자아이디
```

## 3. 주요 사용자

- 개인 크리에이터
- 인플루언서
- 프리랜서
- 일반 사용자
- 여러 SNS와 링크를 한곳에 정리하고 싶은 사람

## 4. 단계별 개발 원칙

마이링크는 기능을 단계별로 추가합니다.

### 현재 단계: 프로필 페이지

이번 단계에서는 사용자가 다른 사람에게 보여줄 수 있는 프로필 페이지와 기본 콘텐츠만 구현합니다.

포함 범위:

- 프로필 사진
- 이름
- 소개 문구
- 소셜 미디어 아이콘과 링크
- 일반 URL 링크 버튼
- 섹션 구분 헤더
- 기본 토스 스타일 디자인
- `localStorage` 기반 데이터 저장

### 이후 단계

다음 기능들은 현재 단계에서 구현하지 않습니다.

- 회원가입과 로그인
- 실제 또는 Mock 인증 화면
- 관리자 대시보드
- 별도 통계 화면
- 방문자 및 링크 클릭 분석
- 백엔드 서버
- 데이터베이스
- 결제 및 유료 플랜

## 5. 현재 단계의 핵심 목표

사용자가 자신의 프로필 페이지를 확인하고, 프로필과 링크 정보를 수정한 뒤 새로고침해도 내용이 유지되는 것을 목표로 합니다.

이번 단계에서는 서버 없이 브라우저의 `localStorage`만 사용합니다.

## 6. 사용자 시나리오

사용자 역할은 공개 프로필을 확인하는 **방문자**와 프로필을 만들고 관리하는 **소유자**로 구분합니다.

### 6.1 방문자 시나리오

#### 시나리오 1: 공개 프로필 확인

1. 사용자가 마이링크 프로필 페이지에 접속합니다.
2. 서비스는 소유자가 저장한 프로필 사진, 이름, 소개, 소셜 링크와 일반 링크를 표시합니다.
3. 방문자는 소유자의 프로필과 콘텐츠를 확인합니다.

#### 시나리오 2: 공개 링크 이용

1. 방문자가 프로필에서 관심 있는 소셜 미디어 아이콘이나 일반 링크 버튼을 찾습니다.
2. 링크 제목, 설명, 썸네일 등을 확인합니다.
3. 방문자가 링크를 클릭하면 설정된 외부 URL로 이동합니다.

#### 시나리오 3: 모바일에서 공개 프로필 확인

1. 방문자가 모바일 화면에서 프로필 페이지에 접속합니다.
2. 프로필 정보와 소셜 미디어 아이콘이 가독성 있게 표시됩니다.
3. 링크 버튼이 세로로 정렬되어 쉽게 읽고 누를 수 있습니다.

### 6.2 소유자 시나리오

#### 시나리오 1: 처음 방문한 소유자가 기본 프로필 확인

1. 소유자가 마이링크 프로필 페이지에 접속합니다.
2. 서비스는 기본 Mock 데이터로 프로필 사진, 이름, 소개, 소셜 링크와 일반 링크를 표시합니다.
3. 소유자는 자신의 공개 프로필이 방문자에게 어떻게 보이는지 확인합니다.

#### 시나리오 2: 프로필 정보 수정 및 저장

1. 소유자가 편집 모드로 전환합니다.
2. 프로필 사진, 이름, 소개 문구를 수정합니다.
3. 화면에 변경 내용이 즉시 반영되는지 확인합니다.
4. 저장 버튼을 누릅니다.
5. 수정한 정보가 브라우저의 `localStorage`에 저장됩니다.
6. 소유자가 페이지를 새로고침해도 수정한 정보가 유지됩니다.

#### 시나리오 3: 소셜 미디어 링크 관리

1. 소유자가 소셜 미디어를 추가하고 플랫폼, 이름, URL을 입력합니다.
2. 필요한 경우 기존 소셜 미디어의 이름이나 URL을 수정합니다.
3. 사용하지 않는 소셜 미디어를 삭제하거나 표시 순서를 변경합니다.
4. 공개 미리보기에서 소셜 미디어 아이콘을 클릭해 설정한 URL로 이동하는지 확인합니다.

#### 시나리오 4: 일반 링크와 섹션 구성

1. 소유자가 `포트폴리오`, `추천 링크`와 같은 섹션을 추가합니다.
2. 각 섹션 아래에 링크 제목, URL, 설명과 썸네일을 입력해 일반 링크를 추가합니다.
3. 링크와 섹션의 순서를 드래그 앤 드롭으로 변경합니다.
4. 링크를 수정하거나 삭제하고, 공개 미리보기에서 버튼을 눌러 외부 URL로 이동하는지 확인합니다.

## 7. 프로필 페이지 기능

### 7.1 프로필 정보

프로필 영역에는 다음 정보를 표시합니다.

- 프로필 사진
- 이름
- 짧은 소개 문구

프로필 정보는 기본 Mock 데이터를 제공하며, 사용자가 편집할 수 있습니다.

### 7.2 소셜 미디어

프로필 페이지에 소셜 미디어 아이콘을 표시합니다.

초기 지원 대상:

- Instagram
- YouTube
- TikTok
- Facebook
- X
- Threads
- LinkedIn
- 네이버 블로그
- 카카오톡

소셜 미디어 기능:

- 소셜 미디어 추가
- 이름과 URL 수정
- 삭제
- 표시 순서 변경
- 아이콘 클릭 시 해당 URL로 이동

### 7.3 일반 URL 링크

일반 링크는 버튼 형태로 표시합니다.

링크에 설정할 수 있는 정보:

- 버튼 제목
- URL
- 설명
- 썸네일
- 아이콘
- 버튼 스타일

링크 기능:

- 링크 추가
- 링크 수정
- 링크 삭제
- 표시 순서 변경
- 버튼 클릭 시 외부 URL로 이동

### 7.4 섹션 구분 헤더

링크를 주제별로 구분하기 위한 텍스트 헤더를 제공합니다.

예시:

- 내 채널
- 포트폴리오
- 추천 링크
- 문의하기

섹션 기능:

- 섹션 추가
- 제목 수정
- 삭제
- 링크와 섹션 사이에 배치

## 8. 편집 방식

프로필 페이지 안에서 편집 모드와 공개 미리보기 모드를 구분합니다.

편집 기능:

- 프로필 정보 수정
- 소셜 미디어 관리
- 링크 관리
- 섹션 관리
- 드래그 앤 드롭으로 링크와 섹션 순서 변경
- 변경 내용을 화면에 즉시 반영
- 저장 버튼을 누르면 `localStorage`에 저장

## 9. 저장 방식

이번 단계에서는 백엔드와 데이터베이스를 사용하지 않습니다.

브라우저 `localStorage`에 다음 데이터를 저장합니다.

```text
mylink_profile
mylink_social_links
mylink_content_items
```

처음 접속하면 기본 Mock 데이터가 표시됩니다. 사용자가 데이터를 수정하고 저장하면 이후 접속과 새로고침에서도 저장된 내용이 표시됩니다.

## 10. 전역 상태 관리

전역 상태 관리는 `Zustand`를 사용할 예정입니다.

현재 단계에서는 프로필 페이지에 필요한 상태만 관리합니다.

```text
profileStore
- profile
- socialLinks
- contentItems
- updateProfile()
- addSocialLink()
- updateSocialLink()
- deleteSocialLink()
- addContentItem()
- updateContentItem()
- deleteContentItem()
- reorderContentItems()
- saveToLocalStorage()
```

Zustand의 영속화 기능을 활용해 프로필 페이지 데이터를 `localStorage`와 연결합니다.

인증 상태, 통계 상태, 대시보드 상태는 현재 스토어에 포함하지 않습니다.

## 11. 디자인 방향

`design.md`에 정의된 토스 스타일을 기본 디자인으로 사용합니다.

- Pretendard 계열 글꼴
- 토스 블루 중심의 색상
- 밝고 깔끔한 배경
- 둥근 카드와 버튼
- 넉넉한 여백
- 명확한 텍스트 계층
- 버튼과 카드의 자연스러운 눌림 상태

## 12. 반응형 기준

프로필 페이지는 PC 화면을 우선으로 설계합니다.

지원 화면:

1. PC
2. 태블릿
3. 모바일

PC에서는 프로필 페이지와 편집 영역을 넓게 사용할 수 있어야 하며, 모바일에서는 프로필과 링크 버튼이 세로로 읽기 쉽게 표시되어야 합니다.

## 13. 현재 단계에서 제외하는 기능

- 회원가입
- 로그인
- 비밀번호 찾기와 변경
- Mock 인증
- 관리자 대시보드
- 방문자 통계
- 링크 클릭 통계
- 분석 차트
- 실제 백엔드 API
- 데이터베이스
- 이메일 인증
- 커스텀 도메인
- 결제와 유료 플랜
- 팀·협업 기능
- 여러 테마 선택 기능

## 14. 현재 단계 완료 기준

- 프로필 페이지가 표시됩니다.
- 프로필 사진, 이름, 소개를 수정할 수 있습니다.
- 소셜 미디어 아이콘과 링크를 관리할 수 있습니다.
- 일반 URL 링크 버튼을 관리할 수 있습니다.
- 섹션 구분 헤더를 관리할 수 있습니다.
- 링크와 섹션 순서를 변경할 수 있습니다.
- 수정 내용이 화면에 즉시 반영됩니다.
- 데이터를 `localStorage`에 저장할 수 있습니다.
- 새로고침 후에도 저장된 데이터가 유지됩니다.
- PC와 모바일 화면에서 사용할 수 있습니다.
- 토스 스타일의 기본 디자인이 적용됩니다.
- 대시보드와 통계 기능은 아직 표시되지 않습니다.

> 이 문서는 현재 시연 단계의 범위를 정의합니다. 이후 단계에서 인증, 대시보드, 통계 기능을 별도로 추가합니다.
