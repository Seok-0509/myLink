# 마이링크 텍스트 기반 와이어프레임

## 1. 문서 목적

마이링크 프로필 페이지의 화면 구조와 사용자 흐름을 텍스트로 정의한다. 현재 단계의 시연 범위인 공개 프로필과 프로필 편집 기능을 대상으로 하며, 실제 UI 디자인 전의 구조 확인을 목적으로 한다.

## 2. 화면 목록

| 화면/상태 | 설명 | 진입 경로 |
| --- | --- | --- |
| 공개 프로필 | 방문자가 보는 기본 프로필 화면 | `/사용자아이디` 접속, 미리보기 모드 |
| 편집 모드 | 소유자가 프로필과 콘텐츠를 수정하는 화면 | 공개 프로필의 `편집` 버튼 |
| 프로필 정보 편집 | 사진, 이름, 소개 수정 영역 | 편집 모드 내 프로필 카드 |
| 소셜 링크 편집 | 소셜 링크 추가·수정·삭제 영역 | 편집 모드 내 소셜 링크 카드 |
| 콘텐츠 편집 | 섹션과 일반 링크 관리 영역 | 편집 모드 내 콘텐츠 관리 영역 |
| 링크 입력/수정 폼 | 일반 링크 또는 소셜 링크 입력 패널 | 각 항목의 추가·수정 버튼 |

### 4.3 공개 화면 동작

- 소셜 아이콘 또는 링크 버튼을 누르면 설정된 외부 URL로 이동한다.
- 링크에 URL이 없거나 유효하지 않으면 이동하지 않고 입력 오류 상태를 표시한다.
- 긴 제목과 설명은 화면 너비에 맞춰 줄바꿈한다.
- 콘텐츠가 없는 섹션은 공개 화면에 표시하지 않는다.
- 소유자용 `편집` 버튼은 현재 단계에서 항상 표시되는 시연용 진입점으로 둔다.

## 7. 상태 및 피드백

```text
[편집 시작]
    |
    +--> 입력 중: 미리보기 즉시 업데이트
    |
    +--> 저장 전: 상단 저장 버튼 활성화
    |
    +--> 저장 성공: "저장되었습니다" 토스트 + 저장 버튼 비활성화
    |
    +--> 저장 실패: "저장하지 못했습니다" 토스트 + 입력값 유지
    |
    +--> 저장하지 않은 변경 후 이탈: 확인 모달
                         ┌──────────────────────────────┐
                         │ 저장하지 않은 변경이 있습니다. │
                         │ 페이지를 나가시겠어요?         │
                         │ [계속 편집] [저장 후 나가기]    │
                         └──────────────────────────────┘
```

필수 입력 오류 예시:

- 이름: `이름을 입력해주세요.`
- 소셜 URL/일반 URL: `올바른 URL을 입력해주세요.`
- 링크 제목: `버튼 제목을 입력해주세요.`
- 중복되거나 비어 있는 섹션 제목: `섹션 제목을 확인해주세요.`

## 8. 반응형 규칙

| 구분 | PC | 태블릿 | 모바일 |
| --- | --- | --- | --- |
| 공개 프로필 | 중앙 고정형 콘텐츠 열 | 콘텐츠 열 축소 | 전체 폭 세로 배치 |
| 편집 모드 | 좌측 편집 / 우측 미리보기 2열 | 편집 중심, 미리보기 접기 가능 | 편집과 미리보기 탭 전환 |
| 링크 버튼 | 넓은 카드형 버튼 | 화면 폭에 맞춤 | 한 줄 또는 2줄 줄바꿈 |
| 소셜 아이콘 | 아이콘+이름 또는 아이콘 | 아이콘 중심 | 아이콘 중심, 터치 영역 확대 |
| 드래그 정렬 | 마우스 드래그 | 터치 드래그 | 핸들 기반 터치 드래그 |

## 9. 데이터와 화면 매핑

```text
profile
├─ profileImage  -> 공개 프로필 상단 이미지
├─ name          -> 프로필 이름
└─ bio           -> 소개 문구

socialLinks[]
├─ platform      -> 소셜 아이콘
├─ name          -> 아이콘 접근성 이름/표시 이름
└─ url           -> 외부 이동 주소

contentItems[]
├─ type: section -> 섹션 구분 헤더
├─ type: link    -> 일반 링크 버튼
├─ title         -> 섹션 제목 또는 버튼 제목
├─ description   -> 링크 설명
├─ thumbnail     -> 링크 썸네일
├─ icon          -> 링크 아이콘
├─ style         -> 버튼 스타일
└─ order         -> 표시 순서
```

저장 키:

- `mylink_profile`
- `mylink_social_links`
- `mylink_content_items`

## 10. MVP 확인 체크리스트

- [ ] 공개 프로필에서 사진, 이름, 소개가 보인다.
- [ ] 소셜 아이콘과 일반 링크가 세로로 읽기 쉽게 보인다.
- [ ] 소셜 링크를 추가·수정·삭제할 수 있다.
- [ ] 일반 링크를 추가·수정·삭제할 수 있다.
- [ ] 섹션을 추가·수정·삭제할 수 있다.
- [ ] 링크와 섹션 순서를 변경할 수 있다.
- [ ] 편집 내용이 미리보기에 즉시 반영된다.
- [ ] 저장 성공 여부가 사용자에게 표시된다.
- [ ] 새로고침 후 저장 내용이 유지된다.
- [ ] PC와 모바일 레이아웃이 모두 사용 가능하다.
- [ ] 회원가입, 로그인, 대시보드, 통계 화면은 표시하지 않는다.
